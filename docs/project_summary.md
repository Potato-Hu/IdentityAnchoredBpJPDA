# 项目摘要

## 1. 项目定位

SwarmJam 是一个面向多无人机协同场景的**关键目标优先多目标跟踪、数据关联与集中式融合研究平台**。当前代码主线是统计目标跟踪与规则式协同追踪，不是多智能体强化学习：仓库中没有神经网络策略、训练循环、经验回放或学习化关联评分器。

项目研究的核心问题是：

> 当外部关键目标先验存在延迟、噪声和漏报，各友方无人机只能获得局部匿名观测，且非关键目标与虚警共同制造关联歧义时，如何持续、准确并保持身份一致地跟踪关键目标。

## 2. 当前端到端流程

当前实现形成了可直接运行的闭环：

```text
三维场景与目标运动
  → 带标签的弱全局关键目标先验
  → 各无人机的局部匿名候选集
  → 单机数据关联与递推航迹
  → 集中式标签分组、门控与协方差交叉融合
  → 关键航迹到无人机的距离型任务分配
  → 离散三维追踪控制
  → 指标、轨迹、运行时间与图表导出
```

上述模块均已接入 `SwarmEnv`。默认配置使用 `local_only + labeled_anchor_bp_jpda + hungarian`。

## 3. 已实现的主要能力

### 3.1 场景与感知

- 三维关键目标、非关键目标和友方无人机初始化；
- Gauss-Markov、随机游走及场景化非关键目标运动约束；
- 带更新周期、随机延迟、相关偏差、独立噪声和漏报的全局关键目标先验；
- 带探测半径、距离/密度相关探测率、测量噪声和泊松杂波的局部匿名观测；
- 均匀杂波与目标邻域热点杂波混合。

### 3.2 数据关联与递推跟踪

当前支持：

- `none`：最近局部候选基线；
- `prior_only`：仅使用带标签外部先验和运动预测；
- `bp_jpda`；
- `hard_anchor_bp_jpda`；
- `covariance_anchor_bp_jpda`；
- `labeled_anchor_bp_jpda`（IA-BP-JPDA）；
- `gm_phd`；
- `lmb`；
- `delta_glmb`。

递推运动先验支持单一 CV 或 IMM。默认 IMM 模型组包含 `cv`、`ca`、`ct_left` 和 `ct_right`，可用于考察跟踪模型与真实运动模型之间的失配。

### 3.3 集中式融合

各无人机输出带关键目标索引的局部后验航迹。融合中心将相对状态转换到全局坐标，加入无人机定位不确定性，按关键索引分组，经过置信度筛选和马氏距离一致性门控后，使用协方差交叉（Covariance Intersection）逐项融合。

当前融合依赖已有关键标签进行分组，并非完全无标签的跨无人机航迹关联。系统同时假设所有局部航迹摘要可以同步、无损地送达融合中心。

### 3.4 任务分配与控制

默认的 `hungarian` 模式根据无人机到一步预测关键航迹的距离构造代价，并加入换目标惩罚。当前求解器对小规模问题采用排列穷举，对较大或矩形问题回退到贪心分配；名称沿用配置项，并未依赖 SciPy 的 Hungarian 实现。

控制器从 26 个三维运动方向中选择与目标方向最一致的动作；未分配或航迹无效时执行停止动作。因此任务分配和控制已经可运行，不再只是占位接口。

## 4. 评估与实验入口

`src/tracking/metrics.py` 已实现：

- 单目标位置误差与有效航迹 RMSE；
- 覆盖率惩罚 RMSE；
- OSPA 与 GOSPA；
- 每步跟踪数量和覆盖率；
- ID Switch；
- 航迹碎片数；
- 关联与融合耗时统计。

主要实验入口：

- `python main.py`：场景与基础轨迹可视化；
- `python -m src.runner.export_tracking_rollout --no-show`：单次闭环跟踪实验；
- `python -m src.runner.run_tracking_monte_carlo --num-seeds N`：同种子方法对比；
- `python -m src.runner.run_nonkey_density_sweep --num-seeds N`：非关键/关键目标密度实验。

| `src/simulation/` | 场景初始化、真实运动与轨迹生成 |

## 6. 当前边界

当前版本不包含：

- 强化学习、监督学习或任何神经网络训练；
- 学习化关联评分模块；
- 无人机间原始测量共享和通信协议；
- 带宽、丢包或异步融合模型；
- 连续控制和发射功率控制动作；
- 完全无标签的跨无人机航迹匹配。

干扰模块会计算并导出基于自由空间路径损耗的接收功率，但这些量尚未进入关联似然、任务分配代价或控制决策。

## 7. 推荐项目表述

建议在 README、汇报或论文背景中使用以下表述：

> SwarmJam 面向弱全局先验、局部匿名观测和非关键目标干扰条件下的多无人机关键目标跟踪，采用经典递推数据关联、带标签先验锚定、集中式协方差交叉融合和规则式协同追踪，重点评估关键航迹的精度、覆盖率与身份连续性。

该表述对应当前可执行代码，不把尚未实现的学习模型或通信机制描述为现有能力。
