# 项目摘要

## 1. 项目定位

SwarmJam 当前更适合被表述为一个面向多无人机协同场景的**关键目标优先多目标跟踪与数据关联研究平台**，而不是一个单纯以强化学习策略优化为中心的项目。仓库已经具备弱全局关键先验、局部匿名候选观测、经典递推关联基线、集中式航迹融合与基础评估能力，因此非常适合作为“学习化关联增强经典跟踪框架”的研究载体。

## 2. 核心问题

本文关注的问题不是“让所有目标平均意义上都跟得更好”，而是：

> 在弱先验、局部匿名观测、非关键目标干扰存在的条件下，研究关键目标优先的学习化数据关联方法，使关键目标的连续性、身份一致性和漏跟踪代价优先得到优化。

与传统对称式多目标关联相比，这里的任务目标更强调：

- 关键目标的持续可跟踪性
- 关键目标身份的一致保持
- 干扰目标贴近时的歧义消解能力
- 模型失配和观测不完备条件下的稳定性

## 3. 研究价值

这个问题设定有三个直接好处：

- 不需要与 `JPDA`、`LMB`、`GM-PHD` 做“全流程替代式”的正面对抗，而是聚焦它们最脆弱的关联环节。
- 可以自然引入时间序列表征、图结构建模和强化学习中常见的表征学习思路，把学习模型的优势放在经典方法最需要帮助的位置。
- 创新点可以围绕“关键目标优先”展开，研究目标更清晰，也更容易通过连续性、身份保持和漏跟踪代价等指标讲清楚方法价值。

## 4. 与当前仓库的对应关系

当前代码已经具备这条研究路线所需的主要骨架：

- `src/sensing/global_sensor.py` 提供关键目标弱全局先验
- `src/sensing/local_sensor.py` 提供局部匿名候选观测
- `src/sensing/association.py` 提供 `none`、`bp_jpda`、`gm_phd`、`lmb` 等经典关联/递推基线
- `src/tracking/fusion_center.py` 与 `src/tracking/fusion.py` 提供集中式局部航迹汇聚与融合
- `src/tracking/metrics.py` 已支持 `key-target RMSE` 与 `key-target OSPA`

因此，项目下一阶段最合理的目标不是重新发明一套全新的滤波器，而是在现有经典后端之前加入一个**关键目标优先的学习化关联评分模块**。

## 5. 推荐表述

建议在摘要、开题或汇报中统一使用如下研究表述：

> 经典关联方法在模型失配、弱先验、干扰目标贴近和长期身份保持方面存在局限。本文提出一种关键目标优先的学习化关联评分机制，用于增强经典多目标跟踪框架在复杂协同场景中的稳定性与身份一致性。
