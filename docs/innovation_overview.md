# 创新点概述

## 1. 创新边界

本项目的创新不建议铺得过大，而应收敛到“学习化关联增强经典后端”这一主线。重点不是宣称“神经网络替代传统滤波器”，而是说明：在关键目标优先、多候选歧义和弱先验条件下，经典方法最脆弱的是关联评分与歧义消解环节，而这正是学习模型最有价值的切入点。

## 2. 三层创新

### 2.1 问题定义创新

本文研究的不是普通多目标关联，而是**关键目标优先关联**。优化目标不再是所有目标的平均误差最小，而是优先降低：

- 关键目标身份切换
- 关键目标漏跟踪时长
- 关键目标轨迹中断

这使得问题定义从“对称多目标估计”转向“带优先级的关键目标连续跟踪”。

### 2.2 方法创新

方法上采用“学习模块 + 经典后端”的混合结构。学习模型不直接替代整套贝叶斯递推，而是输出：

- `track-candidate association score`
- 漏检概率修正
- 存在概率修正
- 歧义分配时的优先级提示

这些输出再送入 `JPDA`、`LMB` 或相近的经典递推更新框架中完成后验估计。这样既保留了经典方法在可解释性和递推一致性上的优势，也能借助学习模型提升复杂歧义场景下的鲁棒性。

### 2.3 机制创新

真正值得强调的不是“用了 GNN”或者“用了时序网络”，而是把以下四类信息同时编码进关联网络：

- 时间连续性
- 弱全局关键先验
- 局部多候选匿名观测
- `key / non-key` 混淆关系

也就是说，创新点落在“如何把关键目标优先机制编码进关联评分网络”，而不只是套一个通用图网络做分类。

## 3. 推荐技术主张

最推荐的技术主张是：

> 本文提出一种面向关键目标优先关联的学习化评分机制，在弱全局先验与局部匿名观测条件下，对经典多目标跟踪后端的关联概率、漏检分支与存在分支进行自适应修正，从而增强关键目标轨迹的连续性与身份一致性。

## 4. 应避免的表述

以下两种说法应尽量避免：

- “本文使用神经网络替代传统关联方法。”
- “本文主要通过 RMSE 证明学习模型优于经典方法。”

更好的表述方式是：

- “本文增强的是经典关联最脆弱的评分与歧义消解环节。”
- “本文重点提升关键目标的连续性、身份一致性与漏跟踪鲁棒性。”

## 5. 指标主张

实验指标应围绕研究主张组织，而不是只报整体位置误差。推荐按以下优先级展开：

- `key-target OSPA`
- `key-target RMSE`
- `ID switch count`
- `track fragmentation count`

其中后两项都来自多目标跟踪评估领域：

- `ID switch count` 常用于多目标跟踪与 MOTChallenge 一类评估，表示同一真实目标被分配到不同估计轨迹身份的次数。
- `track fragmentation count` 也常用于多目标跟踪，表示一条真实轨迹在“已被跟踪”后又中断、随后再次恢复的次数。

这两个指标比单纯位置误差更能体现“关键目标优先关联”的实际价值。
